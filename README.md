# Harry Designs - Designer Portfolio Website

A stunning, modern portfolio website for a creative designer specializing in logo design and product packaging. Built with cutting-edge web technologies to showcase work with beautiful animations and effects.

## 🎨 Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive**: Fully responsive across all devices (mobile, tablet, desktop)
- **Interactive Portfolio**: Filter and view logo and packaging design work
- **Smooth Animations**: Beautiful animations powered by Framer Motion
- **Contact Form**: Easy-to-use contact form for client inquiries
- **Social Integration**: Links to social media profiles

## 🚀 Tech Stack

- **React** - Modern UI library
- **Vite** - Fast build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library for React
- **React Icons** - Beautiful icon library

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/Jayasurya-JK/Harry-Designs.git
cd Harry-Designs
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

5. Preview production build:
```bash
npm run preview
```

## 🎯 Sections

- **Hero**: Eye-catching landing section with animated background
- **About**: Designer skills and statistics
- **Portfolio**: Showcase of logos and packaging designs with filtering
- **Contact**: Contact form and social media links

## 🎨 Customization

To customize the content:

1. **Colors**: Edit `tailwind.config.js` to change the color scheme
2. **Content**: Modify component files in `src/components/`
3. **Portfolio Items**: Update the portfolio array in `src/components/Portfolio.jsx`
4. **Contact Info**: Update contact details in `src/components/Contact.jsx`
